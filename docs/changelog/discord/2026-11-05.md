## 🧱 Recursive folds: the control rail opens as deep as you want

- The rail had two levels (knobs, then one Fine-tune drawer). It is now a tree with one repeating unit — the **fold** — nesting as deep as you want: Colour → Fine-tune → Hues → Every colour, individually.
- Touch anything inside a fold and it is **pinned**: it stops following the broad knob above it while everything else keeps following. Closed folds show how many pins are inside, and any fold can be unpinned to smooth it back.
- Clay, not a spreadsheet: rough shapes first, detail only where you want it. Depth is available, never imposed.
- Pin keys didn't change, so saved systems and old exports load as they did, with their pins showing up in the new folds.
- Checked in a real browser: pinning three levels down raises the count on every fold above it, unpinning an inner fold leaves its siblings alone, pins survive a reload. 39 tests pass.
- Limits: still one rail — no search across controls, and a deep pin is only discoverable by opening the folds above it.

## 🧪 Nine presets, and the readability checks six of them were failing

- The prototype became a repo: modules split by responsibility, no dependencies, no build step, tests under `node --test`, CI on Node 22 and 24, GitHub Pages serving `main` directly.
- The readability panel shows five contrast checks; the tests apply the same ones to every preset. Six of the nine failed.
- Button labels were picked by OKLCH lightness as a stand-in for contrast — but WCAG contrast follows relative luminance, so a saturated cyan or orange at the same lightness got a white label that didn't read (Hardware panel 3.53 → 5.22, Glassy 3.18 → 5.63).
- Both candidate labels are now built and the higher-contrast one kept, with two presets' accent lightness nudged where neither label reached 4.5. Borders in dark mode were too close to the page (Terminal 1.19, Mission control 1.25, Flames 1.21); the steps are now the smallest values that pass.
- The rule the fix rests on: presets pass the checks rather than the thresholds being loosened. A preset that can't pass has to change.
